# ResearchNote

如果你也是一个科研小白，不知道怎么精读文献，那么这款工具很适合你。

## 📌 是什么？

ResearchNote 是一个**开箱即用的单文件网页工具**，主体只有一个 `研究笔记生成器.html`，无需安装任何软件或依赖，下载后双击即可在浏览器中打开。

它把「文献阅读笔记模板」和「代码复现记录模板」做成了可视化表单，填写后自动生成与模板格式一致的 Markdown 文件。导出的md文件，可以导入飞书查看，能够获得更好的阅读体验。

## 🎯 作用

- 📖 **文献阅读笔记**：按模板结构记录标题、摘要复述、引言（背景 / 问题 / 贡献）、相关工作、方法、实验、结论等内容
- 💻 **代码复现记录**：记录仓库链接、环境配置流程、报错与解决方案、核心模块代码、实验结果
- ➕ 分组条目（观点、新方法、报错、核心模块等）可**自由添加和删除**，数量不限
- 🏷️ 分组标签名（如「观点1」「新方法1」）可直接修改，留空时自动使用默认名称
- 👀 下载前可**在线预览**生成的文件效果
- 💾 填写内容**自动保存在浏览器本地**，刷新或重新打开页面不会丢失
- 📄 支持单独下载或一键下载全部，得到两个 `.md` 文件

## 🚀 怎么使用？

1. 下载并双击 `研究笔记生成器.html`，用浏览器打开（推荐 Chrome / Edge）
2. 通过顶部标签页在「文献阅读笔记」和「代码复现记录」之间切换
3. 在表单中填写内容；带底色的小输入框是可修改的分组标签名
4. 需要更多条目时，点击卡片底部的「添加」按钮；删除条目点击其右上角的删除按钮
5. 点击「预览」可查看生成效果，确认无误后点击底部下载按钮
6. 选择「下载文献笔记」「下载复现记录」单独导出，或点击「一键下载全部」同时得到两个文件
7. 下次打开页面时，上次填写的草稿会自动恢复；如需重新填写，点击「清空」即可

> ⚠️ 提示：一键下载全部时，若浏览器询问是否允许下载多个文件，请选择「允许」；草稿保存在当前浏览器中，清理浏览器数据会使其丢失。
